# TaskAPI

Учебное приложение для управления задачами: Go HTTP API, PostgreSQL и веб-интерфейс на HTML/CSS/JavaScript.

## Возможности

- Просмотр и создание задач.
- Отметка задачи выполненной и удаление задач.
- Хранение задач в PostgreSQL между перезапусками.
- Веб-интерфейс с фильтрами и статистикой.

## Запуск

Требуются Go 1.26.8 или новее и PostgreSQL. Создайте отдельную базу и пользователя PostgreSQL с правом создавать таблицы в этой базе.

```bash
cp .env.example .env
# Отредактируйте .env: укажите свои имя пользователя, пароль, порт и базу.
set -a
. ./.env
set +a
go run .
```

Команды рассчитаны на Bash и запускаются из каталога проекта. Приложение читает `DATABASE_URL` из окружения; файл `.env` загружается указанными командами, а не автоматически. Таблица `tasks` создаётся при запуске.

Откройте http://localhost:8080. Параметр `sslmode=disable` в примере предназначен для локальной разработки.

## API

| Метод | Путь | Действие |
| --- | --- | --- |
| GET | `/tasks` | Получить задачи |
| POST | `/tasks` | Создать задачу: `{"title":"Изучить Go"}` |
| PATCH | `/tasks/{id}` | Отметить задачу выполненной |
| DELETE | `/tasks/{id}` | Удалить задачу |

## Проверки и ограничения

```bash
go build ./...
go vet ./...
go test ./...
```

Существующие тесты обработчиков написаны для прежнего хранилища в памяти и требуют обновления для PostgreSQL. Сейчас они вызывают обработчики без подключения к БД и не являются рабочими интеграционными тестами.

В учебной версии используется одно соединение `pgx.Conn`; для параллельной нагрузки нужен пул соединений. Авторизация отсутствует, сервер слушает порт 8080 на всех интерфейсах. Используйте приложение в локальной доверенной среде.

## Секреты

Не добавляйте `.env`, пароли, ключи и дампы базы в Git. В репозитории хранится только `.env.example` с заменителем пароля. Если настоящий пароль ранее раскрывался, смените его в PostgreSQL и обновите локальный `.env`.
